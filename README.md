# Trends Management — Luxury Event Experiences

A premium, production-grade event curation landing page designed for discerning clients globally. Featuring an elegant editorial magazine layout, smooth inertia-scrolling, tactile paper-matte grain textures, and interactive responsive animations.

Designed & Developed with 🖤 by **[CodeCloverStudio](https://codecloverstudio.netlify.app/)**.

---

## ✨ Features

- **Tactile Paper Grain Texture** — An overlay using a lightweight, high-performance SVG noise filter to emulate luxurious physical stationery.
- **Glassmorphic Morphing Navbar** — Navigation docks that transition dynamically into a compact floating capsule dock on scroll.
- **Alternating Editorial Rhythm** — A high-end aesthetic alternating between **Deep Velvet Black (`#0A0A0A`)** and **Warm Luxury Cream (`#F7F3EC`)** page divisions.
- **Asymmetric Image Displays** — Art-gallery-inspired tilted frame orientations (`rounded-[2rem]`) with interactive hover straighten animations.
- **Scroll-Triggered Numerical CountUp** — Dynamic, hardware-accelerated numeric statistics counters triggered only when in view.
- **Masonry Layout Gallery** — A responsive Pinterest-style grid highlighting curated event imagery with interactive overlays.
- **Smooth Inertial Scrolling** — Integrates Lenis Scroll with custom ease configurations for premium inertia transitions.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (configured via CSS-first theme directives)
- **Animation**: GSAP, Framer Motion
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React

## 🚀 Getting Started

### 1. Installation
Clone the repository and install the dependencies:
```bash
npm install
```

### 2. Run Development Server
Start the local server with hot module replacement (HMR):
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
Compile and optimize the assets for production deployment:
```bash
npm run build
```
The built static bundle will be generated under the `dist/` directory.
